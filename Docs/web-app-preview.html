How it works (PRD §44)

Book → bus departs → driver's phone pings every ~15s → every passenger on that bus reads the same single position, drawn as the yellow danfo. Signal drop → grey banner + frozen danfo + "last seen". Pushes: departed → approaching (<5 km) → arrived. Tracking stops at completion; only booked passengers can view.

Stored only in this browser — never sent anywhere except map tiles.
